# 끄적

글·댓글·이미지·AI 도우미와 원격 MCP를 제공하는 블로그다. Node.js 24, NestJS API, Next.js 웹, PostgreSQL 17을 사용하며 npm workspace와 Docker Compose로 관리한다.

- **다른 PC·저장소·운영 서버로 넘길 때:** [이관 안내](docs/handover.md)
- **현재 작업·미완료:** [STATUS.md](STATUS.md)
- **작업 규칙:** [AGENTS.md](AGENTS.md)
- **기능 기준:** [REQUIREMENTS.md](REQUIREMENTS.md)
- **개발·배포·백업:** [운영 기준](docs/operations.md#deployment)
- **원격 MCP 연결:** [연결 안내](docs/assistant-mcp.md), [운영 에이전트 지침](docs/assistant-agent-instructions.md)

실제 개발·운영 환경 파일은 암호화해 Git에 보관한다. 복호화 키와 실행 데이터는 Git에 포함되지 않으므로 이관 안내의 별도 인계 항목을 먼저 확인한다.
